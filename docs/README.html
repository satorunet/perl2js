Perl2JS documentation

Perl2JS compiles Perl syntax to JavaScript in the browser. No server, no WebAssembly. Every perl code block in these pages is run through real Perl 5.40 and Perl2JS in CI-style checks (node tools/verify-docs.js docs/*.md), and the output must be identical.

#The 30-second version

HTML
<script src="https://cdn.jsdelivr.net/gh/satorunet/perl2js@main/perl2js.min.js"></script>
<script type="text/perl2js">
  my @langs = qw(Perl JavaScript);
  for my $l (@langs) { print "Hello, $l!\n"; }
  $("#out")->text("done");            # jQuery-style DOM, built in
</script>

The core (perl2js.js) is small on purpose. Everything else (List::Util, DateTime, jQuery-style $, ...) is a separate file in modules/ that is downloaded the first time a program says use ....

Source and issues: github.com/satorunet/perl2js
