本物の Perl との違い

Perl2JS は JavaScript 上で動く Perl 風の言語であり、完全な perl ではありません。これらのドキュメントのプログラムで本物の Perl と照合していますが、まだ違いが残っている点を以下に示します。

#数値と文字列

Perl Perl2JS
64 ビット整数 (9007199254740993) 数値は JavaScript の倍精度浮動小数点数です。2**53 を超える整数は精度を失い、出力は Perl の %.15g 形式になります
"0x10" + 0 は 0、"1_000" + 0 は 1 文字列から数値への同じ変換規則を、一般的なケースについて実装しています。16 進数やアンダースコアを含む文字列では異なる場合があります
1 << 33、~5 は 64 ビットで動作する ビット演算は 32 ビットです
"az"++ は "ba" (マジカルな文字列インクリメント) .. 範囲 ("aa".."ad") では動作します。文字列変数への ++ では動作しません

#リファレンス

リファレンスは Perl と同じように動作します。\$x、\@a、\%h、\&f、$$r、@$r、%$r、$r->[0]、ref($r) (SCALAR ARRAY HASH CODE REF Regexp)、"$r" は ARRAY(0x55d0c8a1f000) のように出力され、==/eq は同一性を比較します。@a = (...) は配列をその場で変更するため、以前に取ったリファレンスからも変更が見え、foreach は要素のエイリアスになります。

異なる点: \$x == \$x は偽になります (\$x と書くたびに新しいリファレンスオブジェクトが作られるため)。また、\$h{k} や \$a[0] (要素へのリファレンス) には対応していません。

#コンテキスト

Perl はリストコンテキストかスカラーコンテキストかを実行時に決めます。Perl2JS はコードの形から決めますが、一般的なケースでは Perl と一致します。

  • 動作するもの: my ($a, $b) = f();、my $n = @a;、my $n = () = $s =~ /x/g;、scalar(@a)、if (@a)、print "n=" . @a。
  • 存在しないもの: wantarray。そのため、sub がリストコンテキストとスカラーコンテキストで異なる動作をすることはできません。
  • リストを返す sub を my $x = f(); のように使うと、Perl では最後の要素が返りますが、Perl2JS ではリスト全体が返ります。

#未実装

wantarray、フォーマット (format STDOUT =)、tie、pos() と \G、sort by_name LIST (ブロックを使ってください: sort { $a <=> $b } LIST)、goto、型グロブ (*name)、AUTOLOAD、DESTROY のタイミング、配列要素とハッシュ要素に対する local。 ファイルとプロセスに関する関数 (open、opendir、system、fork、-e) は、ブラウザには存在しません。 binmode と STDIN は受け付けられて無視され、print STDERR は console.warn に出力されます。

#待機(sleep)

sleep N、Time::HiRes::sleep / usleep、select(undef, undef, undef, $秒) は Perl と同じく本当に待ちます。待っている間は他の処理が動かず、ページも再描画されません。短い待ちや出力順の確認には十分ですが、ページを止めたくない遅延にはタイマーを使います。

Perl2JS
print "start\n";
setTimeout(sub { print "half a second later\n" }, 500);   # the page stays responsive
sleep 1;                                                    # blocks for 1 second
print "done\n";

(setTimeout のコールバックの中でも sleep は使えます。その場合はコールバックの実行中だけブロックします。)

#ブラウザでは Perl より便利な点

$("#id")->... (jQuery 風)、-> または . による DOM や JS オブジェクトの呼び出し、ハイブリッド構文、そして IME で入力した全角記号 (＄ｘ ＝ （１）；) は、対応する半角記号として読み取られます (文字列の中ではそのままです)。

#名前

$_ @_ $0 $1.. $& $+{name} $@ $! $, $\ $/ $| が存在します。@ARGV と %ENV は空で、$0 は main.p2j です。

ここにない違いを見つけましたか? それを示す最小のプログラムと、本物の Perl の出力を添えて issue を開いてください。
