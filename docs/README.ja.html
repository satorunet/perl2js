Perl2JS ドキュメント

Perl2JS は、Perl 風の言語を ブラウザ上で JavaScript にコンパイルします。サーバーも WebAssembly も不要です。 これらのページにあるすべての perl コードブロックは、本物の Perl 5.40 と Perl2JS の両方で CI 風のチェック (node tools/verify-docs.js docs/*.md) にかけられ、出力が一致する必要があります。

やりたいこと 読むページ
使える Perl の構文を例つきで知りたい 対応している構文
Perl と JavaScript を混ぜて使いたい (Math.max、document.getElementById、alert) Perl + JavaScript ハイブリッド
List::Util、JSON::PP、POSIX、DateTime... を使いたい 同梱モジュール
有名な CPAN モジュールが使えるか確認したい 主要な CPAN モジュールの対応状況
自分のモジュール (use Foo::Bar) を書きたい 自作モジュールの書き方
Web ページに組み込み、DOM や jQuery 風の $ を使いたい ブラウザでの使い方
本物の Perl と挙動が違う点を知りたい Perl との違い

#30 秒でわかる使い方

HTML
<script src="https://cdn.jsdelivr.net/gh/satorunet/perl2js@main/perl2js.min.js"></script>
<script type="text/perl2js">
  my @langs = qw(Perl JavaScript);
  for my $l (@langs) { print "Hello, $l!\n"; }
  $("#out")->text("done");            # jQuery-style DOM, built in
</script>

コア (perl2js.js) は意図的に小さく作られています。それ以外の機能 (List::Util、DateTime、jQuery 風の $ など) は modules/ にある別ファイルで、プログラムが最初に use ... と書いたときにダウンロードされます。
