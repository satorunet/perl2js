クイックスタート

    
<script src="https://cdn.jsdelivr.net/gh/satorunet/perl2js@main/perl2js.min.js"></script>
<script type="text/perl2js">
  my $n = 0;
  $("#hello")->on("click", sub {
      $n++;
      $("#hello-n")->text(" ← ${n}回クリックされました");
  });
</script>

    
$("#id") のjQuery風の書き方は、使った時に自動で読み込まれます(modules/jQuery.js)。

Perl人気モジュールの対応状況・自分でモジュールを作る
    
よく使われる順の目安です(公式のランキングではありません)。
      ○ 対応 / △ 一部 / … 未対応(予定) / ✕ ブラウザでは対象外。

    

      モジュールは「パッケージ」として別ファイルです。 use List::Util qw(sum); と書くと、その時だけ
      modules/List/Util.js を読み込みます(コアには入っていないので、使わなければ読み込まれません)。

      コア 約29KB(gzip)+ 使うモジュールだけ(例: List::Util は +1.3KB、DateTime は +3.0KB、jQuery互換は +7.6KB)。
      perl2js.js と同じ場所の modules/ を一緒に置いてください(場所は Perl2JS.libPath = "/path/" で変更できます)。
    


    
定番(Perl標準添付)

    

      
#モジュール状態できること / 備考

      
1strict○未宣言の変数をコンパイル時に行番号付きでエラーにします。

      
2warnings△読み飛ばし(警告は出しません)。

      
3Data::Dumper○本物と同じ形式(bless( {...}, 'Class' ) も)。$Data::Dumper::Indent / Sortkeys / Terse。

      
4List::Util○sum sum0 product min max minstr maxstr first any all none notall reduce reductions shuffle uniq uniqnum pairs pairkeys pairvalues pairmap head tail zip mesh。first { $_ > 3 } @list のブロック形式もOK。

      
5Scalar::Util○blessed reftype looks_like_number refaddr(weaken は何もしません)

      
6POSIX△strftime mktime floor ceil fmod pow round trunc と INT_MAX などの定数。POSIX::floor(..) の形もOK。

      
7Carp○croak carp confess cluck(at line N. 付き)

      
8constant○use constant PI => 3.14; / use constant { A => 1, B => 2 }; / リスト定数(言語機能としてコアに内蔵)

      
9parent / base○use parent -norequire, 'Animal';、@ISA、SUPER::、isa / can / ref

      
10Time::Local○timelocal timegm(_nocheck / _modern / _posix 付きも)

      
11Time::Piece / Time::Seconds○localtime->ymd ->strftime ->add_months ->week など、Time::Piece->strptime、$t + ONE_DAY、($t2-$t1)->days / ->pretty

      
12Time::HiRes△time(小数秒) gettimeofday tv_interval。sleep / usleep はブラウザでは待てないため非対応。

      
13Storable△dclone(ディープコピー。bless と循環参照も保持)freeze thaw。store / retrieve(ファイル)は対象外。

      
14JSON::PP / JSON / JSON::XS○encode_json decode_json to_json from_json、JSON::PP->new->pretty->canonical->encode($data)(pretty は本物と同じ3スペース)。JSONの true/false は 1/0 になります。JSON->stringify / parse(JS側のJSON)も使えます。

      
15Encode○encode decode encode_utf8 decode_utf8。UTF-8 / latin1 / UTF-16 / Shift_JIS / EUC-JP(ISO-2022-JP は decode のみ)。

      
16MIME::Base64 / URI::Escape○encode_base64 decode_base64(url-safe 版も)、uri_escape uri_unescape uri_escape_utf8

      
17File::Basename / File::Spec○basename dirname fileparse、File::Spec->catfile / catdir / splitdir / canonpath(文字列処理のみ。rel2abs などカレントディレクトリが要るものは対象外)

      
18Digest::MD5 / Digest::SHA△md5_hex md5_base64、sha1_hex sha256_hex hmac_sha256_hex ほか、Digest::MD5->new->add(..)->hexdigest。SHA-512 は未対応。

      
19Text::Wrap○wrap fill($Text::Wrap::columns / huge / unexpand など。本物のアルゴリズムの移植)

      
20Term::ANSIColor○color colored colorstrip uncolor、:constants(RED BOLD RESET ...)。出力欄は色を解釈しません。

      
21Math::Trig○pi tan asin acos atan sinh... deg2rad rad2deg great_circle_distance

      
22Test::More○ok is isnt like cmp_ok is_deeply can_ok isa_ok subtest plan done_testing。TAP形式で出力(失敗の詳細も本物と同じ文面)。

      
23Benchmark…未対応(Time::HiRes で計測できます)

      
24Getopt::Long / Cwd / File::Temp / IO::File / Socket / Sys::Hostname✕コマンドライン・ファイル・ネットワークに依存するため、ブラウザでは対象外です。

    


    
人気のCPANモジュール

    

      
#モジュール状態できること / 備考

      
1DateTime / DateTime::Duration○now today new from_epoch add subtract subtract_datetime delta_days truncate set strftime week compare、time_zone => 'Asia/Tokyo'(IANAゾーン)、in_units。
日付の == は同一オブジェクト判定になるため、->epoch == か DateTime->compare を使ってください(< > <=> は使えます)。

      
2Try::Tiny○try { } catch { } finally { };($_ がエラー、戻り値も返せます)。Perl 5.34 の try { } catch ($e) { } はモジュール無しで使えます。

      
3List::MoreUtils△uniq any all none firstidx lastidx indexes firstval minmax part apply after before。zip / natatime / pairwise は未対応。

      
4Moose / Moo / Mouse…has / extends は未対応。package + bless + use parent で代用できます。

      
5LWP::UserAgent / HTTP::Tiny△ブラウザは同期通信できないため、代わりに $->get / post / getJSON / ajax(非同期)を使います。

      
6Text::CSV / YAML / XML::Simple…需要に応じて対応予定。

      
7DBI / Mojolicious / Dancer / Catalyst / Path::Tiny✕データベース・サーバ・ファイルに依存するため、ブラウザでは対象外です。

    


    
Perl2JS独自(ブラウザ向け)

    

      
#機能状態できること / 備考

      
1jQuery互換 $(modules/jQuery.js)○セレクタ・チェーン・on(委譲/名前空間)・css attr val data・DOM操作・fadeIn/Out slide* animate・$->ajax/get/post/getJSON。$( を使うと自動で読み込まれます。本物のjQueryを読み込めばそちらを優先します。

      
2JSオブジェクト直接○document console JSON Math Date などを -> でそのまま呼べます。例: document->getElementById("x")->{value}

    


    
自分でモジュールを作る

    
1ファイル = 1モジュールです。modules/Foo/Bar.js を置けば、use Foo::Bar qw(hello); で使えます。

    
Perl2JS.module({
  name: 'Foo::Bar',
  init(api) {                                   // api: hide, mk(リスト), RT, G(グローバル), use('他モジュール') ...
    return {
      exports:  { hello: (name) => 'Hello, ' + name, PI: 3.14159 },   // 関数 / 定数
      default:  [],                              // use Foo::Bar; だけで取り込む名前
      unary:    ['hello'],                       // 括弧なしで1引数だけ取る  (hello "x" . "y")
      blockfns: { each_pair: '$a, $b' },        // first { ... } @list のようにブロックを取る関数
      classes:  { 'Foo::Bar': SomeClass },      // Foo::Bar->new のような静的呼び出し
    };
  },
});
